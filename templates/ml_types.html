Main Types of Machine Learning

Definition: The algorithm is trained on a labeled dataset where correct answers (ground truth) are provided.

Main Characteristics: Requires labeled inputs/outputs. Directly measures prediction accuracy against target labels.

Problems Solved: Regression (predicting continuous numerical values) and Classification (predicting categorical labels).

Definition: The model analyzes unlabeled data to autonomously discover hidden structures, groupings, or patterns.

Main Characteristics: No pre-defined target variables. Focuses on intrinsic data relationships.

Problems Solved: Clustering, Anomaly Detection, and Dimensionality Reduction.

Definition: An autonomous agent learns decision-making through trial and error by interacting with a dynamic environment.

Main Characteristics: Guided by a system of numerical rewards and penalties.

Problems Solved: Robotics, Video Game AI, Autonomous Navigation, and Decision Optimization.
