Reinforcement Learning

Theoretical Concepts & Project Context

Context

This section explains the foundational concepts of Reinforcement Learning (RL) applied specifically to our 10x10 Grid Environment. In this environment, the agent must navigate from the starting point to the target while avoiding walls and danger zones.

Agent

The decision-maker. In our app, the agent is the virtual robot trying to find the best route through the 10x10 maze.

Environment

The world the agent interacts with. Here, it consists of a 10x10 grid with 68 paths, 20 walls (#), 10 danger zones (D), and 1 goal (T).

State

The agent's current situation. It is represented by the current (Row, Column) coordinates on the grid.

Concept Application in our Project
Action The 4 possible moves: Up, Down, Left, Right.
Immediate Reward Feedback for a single step: +100 for reaching the Target.
Penalty Negative feedback: -50 for Danger Zones, -10 for Walls, -1 for normal steps to encourage speed.
Return The total accumulated reward from a specific state until the end of the episode.

  • Step: A single transition where the agent takes an action, receives a reward, and moves to a new state.
  • Episode: A complete run from the start state (0,0) until the agent reaches the target (9,9) or hits the step limit.
  • Experience: A tuple of data collected during a step: (State, Action, Reward, Next State).
  • Exploration: When the agent chooses random actions to discover new paths.
  • Exploitation: When the agent chooses the action with the highest learned Q-Value.
  • Epsilon-Greedy Strategy: We start with ε = 1.0 (100% exploration) and slowly decay it, forcing the agent to eventually exploit its knowledge.

Q-Learning is the algorithm used to train our agent. Instead of a traditional Q-Table, we use a SGDRegressor model with 400 features (One-Hot Encoding) to estimate the values.

  • Policy (π): The strategy the agent learns. Our goal is to find the optimal policy.
  • Discount Factor (γ): Set to 0.95. It determines how much the agent cares about future rewards versus immediate ones.
  • State Value V(s): The expected return starting from a specific cell and following the policy.
  • Action Value Q(s,a): The expected return of taking a specific action in a specific state, and then following the policy.
