Binary Logistic Regression Concepts

What is Logistic Regression?

Logistic Regression is a supervised learning algorithm used to predict the probability of a categorical target outcome based on input features.

Why Classification?

Although it uses a mathematical equation similar to linear regression, its output passes through a Sigmoid Function to produce probabilities bounded between 0 and 1, mapping directly into discrete classes.

What is Binary Classification?

A classification task where the target variable has exactly two mutually exclusive outcomes (e.g., 0 = No / 1 = Yes).

Classification Threshold

The decision boundary (commonly 0.5) used to convert predicted probabilities into definitive class labels.

Difference: Linear vs Logistic Regression

Linear Regression predicts continuous numbers (e.g., prices), whereas Logistic Regression predicts probabilities for categorical outcomes (e.g., buy vs not buy).
