Logistic Regression Concepts

What is Logistic Regression?

Logistic Regression is a supervised learning algorithm used to solve classification problems. Instead of predicting a continuous number, it estimates the probability that an observation belongs to one of two possible classes, using a sigmoid (S-shaped) function to map any input into a value between 0 and 1.

Why is it considered a classification algorithm?

Although it is called "regression," its output is used to assign a discrete category. The probability produced by the sigmoid function is compared against a classification threshold (commonly 0.5) to decide the final predicted class.

Binary Classification

Binary classification refers to problems where the target variable has exactly two possible classes or labels, typically represented as 0 and 1.

  • Independent Variable (X): The predictor used as input (e.g., hours of sleep).
  • Target Variable (Y): The binary outcome being predicted (0 or 1).
  • Classes / Labels: The two categories the model can assign.
Probability & Threshold
  • Probability of belonging to a class: A value between 0 and 1 produced by the sigmoid function.
  • Classification threshold: The cutoff point (usually 0.5) used to convert a probability into a discrete class (0 or 1).
Linear Regression vs Logistic Regression
  • Output type: Linear Regression predicts a continuous value; Logistic Regression predicts a probability mapped to a discrete class.
  • Function used: Linear Regression fits a straight line; Logistic Regression fits an S-shaped sigmoid curve.
  • Goal: Linear Regression minimizes prediction error on a numeric scale; Logistic Regression maximizes the likelihood of correctly classifying each observation.
