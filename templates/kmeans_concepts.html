Algoritmo K-Means Clustering

El algoritmo de K-Means es un método de aprendizaje no supervisado que se utiliza para segmentar o agrupar un conjunto de datos desordenados en un número fijo (K) de grupos basados en sus características similares.

Conceptos Clave:

  • 📌 Centroides: Son los puntos centrales de cada grupo. El algoritmo los mueve iterativamente para minimizar la distancia matemática hacia los elementos asignados.
  • 📌 Distancia Euclidiana: Es la métrica estándar que utiliza el modelo para calcular qué tan cerca o lejos está un registro respecto a un clúster determinado.
  • 📌 Escalamiento de datos (StandardScaler): Como K-Means depende de distancias, es mandatorio normalizar variables con rangos muy distantes (como Edad e Hipertensión) para que todas tengan el mismo peso estadístico.

Aplicación en este proyecto:

Utilizamos K-Means para segmentar una base de datos con registros de citas médicas, logrando clasificar de forma automatizada los perfiles clínicos, vulnerabilidades y niveles de asistencia de los pacientes.
