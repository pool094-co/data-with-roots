Linear Regression Concepts

What is Linear Regression?

Linear Regression is a supervised learning algorithm that models the mathematical relationship between an independent input variable ($X$) and a continuous dependent target variable ($Y$) using a straight regression line.

Independent Variable (X):

The input predictor factor (e.g., Age of the mobile phone in months).

Dependent Variable (Y):

The output target to predict (e.g., Estimated market price in COP).

Key Elements
  • Relationship between variables: Analyzes how the dependent variable changes as the independent variable varies.
  • Regression line: The best-fit trend line calculated to minimize prediction errors across all data points.
  • Prediction: Calculating expected values for new unseen inputs based on the trained regression line.
